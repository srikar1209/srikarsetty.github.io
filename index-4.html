Complex-Valued Hopfield
Associative Memories

Institution
Mahindra University
Timeline
May 2024 – Jan 2025
Domain
Neural Memory Research

Overview

A standard Hopfield network stores patterns using binary (±1) neuron states. It works like an associative memory: give it a noisy input, and it retrieves the closest stored pattern. But there's a hard limit: a network of N neurons can only reliably store about 0.138N patterns.

This project asked: what if neurons could hold a complex number instead of just ±1? By moving to the complex domain, where each neuron is a point on the unit circle in ℂ, every neuron carries more information, pushing that capacity ceiling higher.

Complex-Valued Extension

Instead of ±1, each neuron now holds a complex phasor, a unit-magnitude complex number defined by a phase angle. The weight matrix uses a Hebbian learning rule adapted for complex arithmetic. Retrieval runs an iterative update that converges from a corrupted input back to the original pattern.

MedBot: Medical Symptom
Analysis & Diagnosis

Institution
Mahindra University
Timeline
Jan 2024 – Jun 2024
Model
Mistral 7B (4-bit)

Overview

Getting timely, structured medical guidance is hard in many regions. General-purpose LLMs give vague health advice that isn't safe or actionable. MedBot is a domain-specific medical AI that takes patient-reported symptoms and returns structured, evidence-informed diagnostic suggestions.

The main constraint: make it run cheaply on consumer hardware, fitting a 7-billion parameter model into a 4-bit quantized footprint without losing clinical relevance.

How It Works

01
Base Model
Mistral 7B, chosen for strong instruction-following. Loaded in 4-bit quantization (bitsandbytes) to fit on a single GPU.
02
LoRA Fine-tuning
Low-Rank Adaptation targets only the attention layers. Fine-tuned on real symptom-diagnosis pairs.
03
Prompt Pipeline
A structured 1024-token prompt guides the model to return consistent, parseable outputs: conditions, severity, and next steps.
04
Deployment
Deployed via GitHub Pages. No local model setup needed, so users get structured medical suggestions directly in the browser.

Impact

4-bit

Packing a domain-tuned model into a 4-bit footprint lets it run on a single GPU, and the structured prompt format makes every response easy to parse and act on downstream.

6 Sorting Algorithms

Bubble Sort
O(n²)
Repeatedly swaps adjacent elements if out of order.
Selection Sort
O(n²)
Finds the minimum and places it at the front each pass.
Insertion Sort
O(n²)

Merge Sort
O(n log n)
Divides the array and merges sorted halves recursively.

O(n log n)
Partitions around a pivot and recurses on both sides.

O(n log n)
